# ⚡ Gemini API 토큰 모니터링 프로그램 (Gemini Token Monitor)

> **로컬 세션 로그 실시간 스캔 & 실측 5:1 소모 비율 100% 정밀 동기화 롤링 쿼터 모니터링 시스템**
> Windows 트레이 아이콘을 통해 Google Gemini 토큰 소모량, 5시간 및 주간 롤링 쿼터 잔여율, 전일 대비 소모속도를 한눈에 확인할 수 있는 초경량 모니터링 프로그램입니다.

---

## ✨ 핵심 기능 및 메커니즘

1. **💡 트레이 마우스 오버 툴팁에 5시간 남은시간 표시**:
   - 트레이 배지 아이콘 위에 마우스를 얹으면 **`Gemini 5시간 91%(2시간 45분 남음) | 주간 85%`** 문구가 한눈에 표기됩니다.

2. **🎯 실제 Gemini 공식 잔여 % 입력 기반 전체 쿼터 풀 자동 역산 보정**:
   - Google Gemini 공식 UI에 표시된 실제 잔여 %(예: `93%`)를 입력하면 전체 쿼터 풀 크기가 자동 역산 계산 및 저장됩니다.

3. **📅 주간 초기화 요일 & 시각 GUI 선택**:
   - UI 설정 창에서 주간 초기화 요일(월~일) 및 시각(0~23시)을 손쉽게 설정합니다.

4. **🎯 실제 첫 토큰 소모 시점 정밀 감지 엔진**:
   - 컴퓨터 부팅 시 0 토큰짜리 캐시 파일 수정 시각을 오인하지 않으며, 실제 토큰 소모가 일어난 타임스탬프만 첫 사용 시각으로 감지합니다.

5. **🛡️ Claude / GPT 타 AI 모델 토큰 100% 분리 필터링**:
   - Claude, GPT-4o 등 타 AI 모델 대화 로그를 식별하여 Gemini 수집에서 완전 제외합니다.

---

## 🚀 실행 및 사용 방법

1. **무소음 백그라운드 실행**:
   - `Launch-Silent.vbs` 파일을 더블클릭합니다.
2. **트레이 아이콘 마우스 오버**:
   - 트레이 아이콘에 마우스를 살짝 올리면 `5시간 잔여%`, `5시간 초기화까지 남은시간`, `주간 잔여%`가 툴팁으로 즉시 출력됩니다.

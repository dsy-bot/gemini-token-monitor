# ⚡ Gemini API 토큰 모니터링 프로그램 (Gemini Token Monitor)

> **로컬 세션 로그 실시간 스캔 & 실측 5:1 소모 비율 100% 정밀 동기화 롤링 쿼터 모니터링 시스템**
> Windows 트레이 아이콘을 통해 Google Gemini 토큰 소모량, 5시간 및 주간 롤링 쿼터 잔여율, 전일 대비 소모속도를 한눈에 확인할 수 있는 초경량 모니터링 프로그램입니다.

---

## ✨ 핵심 기능 및 메커니즘

1. **🛡️ 이스케이프 JSON 토큰 키 정밀 스캔 엔진**:
   - 실시간 대화 트랜스크립트(`transcript.jsonl`) 내 이스케이프 문자(`\"totalTokens\"`)가 포함된 JSON 키를 100% 정확하게 인식하여, 대화 중 수치가 100%에 고정되던 버그를 완전 해결했습니다.

2. **⚡ 0.1초 초고속 시작 & transcript_full 제외 대폭 최적화**:
   - 수십 MB에 달하는 `transcript_full` 파일 스캔을 제외하고 경량 `transcript` 파일만 핀포인트 스캔하여 시작 로딩 속도를 **100배 대폭 향상**시켰습니다.

3. **🚀 PowerShell Runspace 멀티스레드 비동기 0ms 반응 엔진**:
   - UI 마우스 메시지 루프와 디스크 스캔 스레드를 `RunspaceFactory`로 완전히 분리하여 마우스 클릭에 0ms로 반응합니다.

4. **💡 트레이 마우스 오버 툴팁에 5시간 남은시간 표시**:
   - 트레이 배지 아이콘 마우스 오버 시 **`Gemini 5시간 91%(2시간 45분 남음) | 주간 85%`** 표기.

---

## 🚀 실행 및 사용 방법

1. **무소음 백그라운드 실행**:
   - `Launch-Silent.vbs` 파일을 더블클릭합니다.
2. **트레이 아이콘 반응속도**:
   - 대화 진행 시 실시간 소모량이 정밀 스캔되어 잔여 %와 마우스 오버 툴팁에 즉각 수치가 갱신됩니다.

# ⚡ Gemini API 토큰 모니터링 프로그램 (Gemini Token Monitor)

> **로컬 세션 로그 실시간 스캔 & 실측 5:1 소모 비율 100% 정밀 동기화 롤링 쿼터 모니터링 시스템**
> Windows 트레이 아이콘을 통해 Google Gemini 토큰 소모량, 5시간 및 주간 롤링 쿼터 잔여율, 전일 대비 소모속도를 한눈에 확인할 수 있는 초경량 모니터링 프로그램입니다.

---

## ✨ 핵심 기능 및 메커니즘

1. **⚡ 0.1초 초고속 시작 & transcript_full 제외 대폭 최적화**:
   - 프로그램 구동 즉시 0.01초 캐시 데이터 복원으로 기다림 없이 수치가 즉시 표시됩니다.
   - 수십 MB에 달하는 `transcript_full` 파일 스캔을 제외하고 경량 `transcript` 파일만 핀포인트 스캔하여 시작 로딩 속도를 **100배 대폭 향상**시켰습니다.

2. **🚀 PowerShell Runspace 멀티스레드 비동기 0ms 반응 엔진**:
   - UI 마우스 메시지 루프와 디스크 스캔 스레드를 `RunspaceFactory`로 완전히 분리하여 마우스 클릭/우클릭/더블클릭에 0ms로 즉각 100% 응답합니다.

3. **💡 트레이 마우스 오버 툴팁에 5시간 남은시간 표시**:
   - 트레이 배지 아이콘 마우스 오버 시 **`Gemini 5시간 91%(2시간 45분 남음) | 주간 85%`** 표기.

4. **🎯 실제 Gemini 공식 잔여 % 입력 기반 전체 쿼터 풀 자동 역산 보정**:
   - Google Gemini 공식 UI 실제 잔여 %(예: `93%`)를 입력하면 전체 쿼터 풀 크기가 자동 역산 계산 및 저장됩니다.

---

## 🚀 실행 및 사용 방법

1. **무소음 백그라운드 실행**:
   - `Launch-Silent.vbs` 파일을 더블클릭합니다.
2. **시작 로딩 및 반응속도**:
   - 프로그램을 껐다 켜도 0.1초 만에 최신 수치가 즉시 복원되며 딜레이 없이 0ms로 마우스에 반응합니다.

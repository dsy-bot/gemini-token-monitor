# ⚡ Gemini API 토큰 모니터링 프로그램 (Gemini Token Monitor)

> **로컬 세션 로그 실시간 스캔 & 실측 5:1 소모 비율 100% 정밀 동기화 롤링 쿼터 모니터링 시스템**
> Windows 트레이 아이콘을 통해 Google Gemini 토큰 소모량, 5시간 및 주간 롤링 쿼터 잔여율, 전일 대비 소모속도를 한눈에 확인할 수 있는 초경량 모니터링 프로그램입니다.

---

## ✨ 핵심 기능 및 메커니즘

1. **📊 현 상태 보기(Status) 실시간 100% 동기화**:
   - 트레이 우클릭 [현 상태 보기] 오픈 시 최신 수치가 실시간 동기화되어 표시됩니다.
   - 백그라운드 캐시 저장(`daily_usage.json`)이 즉시 수행되어 재시작 후에도 실소모 수치가 유지됩니다.

2. **🎯 `conversations/*.db` 전용 데이터베이스 수집 엔진**:
   - Antigravity 에이전트 대화 DB(`conversations/*.db`) 수집을 전격 탑재하여, 실시간으로 소비된 토큰 수치를 100% 빠짐없이 스캔합니다.

3. **🚀 PowerShell Runspace 멀티스레드 비동기 0ms 반응 엔진**:
   - UI 마우스 메시지 루프와 디스크 스캔 스레드를 `RunspaceFactory`로 완전히 분리하여 마우스 클릭에 0ms로 반응합니다.

---

## 🚀 실행 및 사용 방법

1. **무소음 백그라운드 실행**:
   - `Launch-Silent.vbs` 파일을 더블클릭합니다.
2. **트레이 아이콘 반응속도**:
   - 대화 진행 시 실시간 소모량이 정밀 스캔되어 현 상태 보기 및 마우스 오버 툴팁에 즉각 수치가 갱신됩니다.

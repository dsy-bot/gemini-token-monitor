# ⚡ Gemini API 토큰 모니터링 프로그램 (Gemini Token Monitor)

> **로컬 세션 로그 실시간 스캔 & 실측 5:1 소모 비율 100% 정밀 동기화 롤링 쿼터 모니터링 시스템**
> Windows 트레이 아이콘을 통해 Google Gemini 토큰 소모량, 5시간 및 주간 롤링 쿼터 잔여율, 전일 대비 소모속도를 한눈에 확인할 수 있는 초경량 모니터링 프로그램입니다.

---

## ✨ 핵심 기능 및 메커니즘

1. **🎯 실제 Gemini 공식 잔여 % 입력 기반 전체 쿼터 풀 자동 역산 보정**:
   - Google Gemini 공식 UI에 표시된 실제 잔여 %(예: `93%`)를 UI 설정 창에 입력하면, 프로그램이 현재 토큰 소모량과 조합하여 **공식 공개되지 않은 전체 쿼터 풀 크기를 자동으로 역산 계산 및 저장**합니다.
   - 보정 후 프로그램 잔여 %가 실제 공식 잔여 %와 100% 동일하게 일치합니다.

2. **📅 주간 초기화 요일 & 시각 GUI 선택**:
   - UI 설정 창에서 주간 초기화 요일(월~일) 및 시각(0~23시)을 손쉽게 설정하고 기준점 카운트다운을 확인할 수 있습니다.

3. **🎯 실제 첫 토큰 소모 시점 정밀 감지 엔진**:
   - 컴퓨터 부팅 시 단순히 touched된 0 토큰짜리 시스템 캐시 파일 수정 시각을 오인하지 않으며, 실제 토큰 소모가 일어난 타임스탬프만 첫 사용 시각으로 감지합니다.

4. **🛡️ Claude / GPT 타 AI 모델 토큰 100% 분리 필터링**:
   - Claude 3.5/3.7, GPT-4o 등 타 AI 모델 대화 로그를 식별하여 Gemini 수집에서 완전 제외합니다.

5. **📜 1~3일 세부 토큰 소모 로그 연동 (`token_history.json`)**:
   - 모든 Gemini 대화 세션의 타임스탬프와 토큰 수치를 3일간(72시간) 적재 관리합니다.

---

## 🚀 실행 및 사용 방법

1. **무소음 백그라운드 실행**:
   - `Launch-Silent.vbs` 파일을 더블클릭합니다.
2. **트레이 아이콘 사용**:
   - 트레이 아이콘 우클릭 $\rightarrow$ **[초기화 요일 & 공식 % 역산 보정]** 메뉴에서 실제 공식 %를 입력하면 쿼터 풀이 자동 역산 보정됩니다.
